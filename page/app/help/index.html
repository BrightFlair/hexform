Help with HexForm

HexForm gives every form a secure endpoint, without requiring a server or SDK on your website.

Documentation is on its way.

This area will contain complete setup guides, field references, junk-protection advice, forwarding recipes, and troubleshooting.

Getting started

Create an endpoint, copy its action URL, then use that URL as the action on any HTML form with method="post" . Give each form control a unique name .

Need a hand?

Until the documentation is ready, contact the HexForm team with your endpoint code and a description of what you expected to happen. Never include sensitive submission contents.
